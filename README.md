# Tiseg — таймер на 7-сегментном дисплее с кнопкой

[![Platform](https://img.shields.io/badge/platform-Arduino-blue)](https://www.arduino.cc)
[![Depends](https://img.shields.io/badge/depends-GyverSegment-orange)](https://github.com/GyverLibs/GyverSegment)
[![License](https://img.shields.io/badge/license-MIT-green)](LICENSE)

**Tiseg** — шаблонная библиотека для Arduino, реализующая секундомер на 7-сегментном индикаторе с общим анодом и одной кнопкой управления. Одним вызовом `runTimer()` вы получаете: отсчёт секунд, эффект мигания при смене цифры, паузу, сброс и ожидание после финиша.

Построена поверх [GyverSegment](https://github.com/GyverLibs/GyverSegment) (динамическая индикация) и повторяет логику проверенного скетча-эталона.

## Возможности

- Отсчёт от `0` до любого `maxSeconds` (60, 100, 9999…).
- Одна кнопка — три действия: **старт → пауза → сброс**.
- Эффект «мигания»: дисплей гаснет на вторые 500 мс каждой секунды, а включается уже со следующей цифрой.
- Защита от дребезга кнопки.
- После финиша (`maxSeconds`) дисплей ждёт нажатия для сброса.
- Любое количество разрядов через шаблон: `Tiseg<2>`, `Tiseg<4>`, `Tiseg<6>`…

## Быстрый старт

Полный пример с построчным разбором синтаксиса (`examples/BaseTimer/BaseTimer.ino`):

```cpp
#include <Tiseg.h>                          // 1. подключаем заголовок библиотеки

const uint8_t digitPins[]   = {9, 10, 11, 12};        // 2. массив пинов анодов
const uint8_t segmentPins[] = {1, 2, 3, 4, 5, 6, 7, 8};// 3. массив пинов сегментов
const int BUTTON = 13;                                  // 4. пин кнопки

Tiseg<4> timer(digitPins, segmentPins, BUTTON);        // 5. создание объекта

void setup() {
  timer.begin();                            // 6. инициализация (1 раз)
}

void loop() {
  timer.tick();                             // 7. обновление индикации (каждый цикл!)

  if (timer.isButtonPressed()) {            // 8. проверка кнопки
    timer.runTimer(100);                    // 9. запуск таймера до 100
  }
}
```

| Строка | Синтаксис | Объяснение |
|--------|-----------|------------|
| 1 | `#include <Tiseg.h>` | подставляет содержимое заголовочного файла библиотеки |
| 2–3 | `const uint8_t name[] = {...}` | неизменяемый массив байтов; `[]` без размера — компилятор сам посчитает длину |
| 4 | `const int BUTTON = 9` | именованная константа вместо «магического числа» |
| 5 | `Tiseg<4> timer(...)` | **шаблонная instanция**: `<4>` — число разрядов; `timer` — имя объекта; в скобках — аргументы конструктора |
| 6 | `timer.begin()` | настраивает пин кнопки, выводит `0000`, пауза 2 с |
| 7 | `timer.tick()` | без него дисплей гаснет: динамическая индикация требует постоянного обновления |
| 8 | `if (timer.isButtonPressed())` | метод возвращает `bool` с антидребезгом 50 мс |
| 9 | `timer.runTimer(100)` | блокирующий метод: пока идёт отсчёт, управление не возвращается в `loop()` |

## API: синтаксис методов

### Объявление класса

```cpp
template <uint8_t DIGITS>
class Tiseg {
public:
  Tiseg(const uint8_t* digitPins, const uint8_t* segmentPins, uint8_t buttonPin);
  void begin();
  void tick();
  bool isButtonPressed();
  void showZero();
  void runTimer(int maxSeconds);
private:
  DispBare<DIGITS, true, true> _disp;
  uint8_t _btn;
  bool handlePauseAndExit(int currentNum, bool& blinked);
  void waitForReset();
};
```

### `Tiseg(digitPins, segmentPins, buttonPin)` — конструктор

```cpp
Tiseg<4> timer(digitPins, segmentPins, BUTTON);
```

| Параметр | Тип | Смысл |
|----------|-----|-------|
| `DIGITS` | шаблонный `uint8_t` | количество разрядов дисплея |
| `digitPins` | `const uint8_t*` | указатель на массив пинов анодов |
| `segmentPins` | `const uint8_t*` | указатель на массив пинов сегментов (8 шт.) |
| `buttonPin` | `uint8_t` | пин кнопки |

### `void begin()`
Вызывать **один раз** в `setup()`. Делает: `pinMode(_btn, INPUT_PULLUP)` → `showZero()` → пауза 2000 мс.

### `void tick()`
Вызывать **в каждом проходе** `loop()`. Прокручивает мультиплексирование разрядов.

### `bool isButtonPressed()`
Возвращает `true` при нажатии (LOW). Внутри — антидребезг: повторное чтение через 50 мс.

### `void showZero()`
Выводит `0000` и обновляет дисплей (`clearPrintR` + `update`).

### `void runTimer(int maxSeconds)`
Главный метод. Запускает отсчёт `0 … maxSeconds`. Внутри:
- смена цифры раз в 1000 мс;
- гашение дисплея на 500–1000 мс (эффект мигания);
- нажатие кнопки во второй половине секунды → пауза → второе нажатие → сброс и `return`;
- достижение `maxSeconds` → ожидание нажатия (`waitForReset()`).

### Приватные методы (внутренние)
- `bool handlePauseAndExit(int currentNum, bool& blinked)` — обработка паузы и сброса; возвращает `true`, если таймер нужно прервать.
- `void waitForReset()` — ожидание кнопки после финиша.

## Подробный разбор синтаксиса C++

### 1. `#pragma once`
```cpp
#pragma once
```
Защита от повторного включения заголовка. Без неё двойной `#include` дал бы ошибку «redefinition of class Tiseg».

### 2. Шаблон с числовым параметром
```cpp
template <uint8_t DIGITS>
class Tiseg { ... };
```
`DIGITS` — **не переменная, а константа времени компиляции**. Компилятор для каждого значения создаёт отдельную версию класса:

```cpp
Tiseg<4> a(...);  // скомпилируется класс Tiseg с DIGITS = 4
Tiseg<2> b(...);  // и отдельный класс Tiseg с DIGITS = 2
```

Зачем шаблон, а не аргумент конструктора? Потому что член класса
```cpp
DispBare<DIGITS, true, true> _disp;
```
сам является шаблонным объектом: его размер и пины должны быть известны **до** выполнения программы.

### 3. Указатель на массив: `const uint8_t*`
```cpp
Tiseg(const uint8_t* digitPins, const uint8_t* segmentPins, uint8_t buttonPin)
```
Разбор по частям:

```
const   uint8_t   *   digitPins
  │        │      │      └── имя параметра
  │        │      └── «указатель»: хранит адрес первого элемента массива
  │        └── тип элемента: байт без знака (0…255) — стандарт для пинов
  └── данные по этому указателю менять нельзя (защита от случайной записи)
```

В C++ массивы **не копируются** при передаче в функцию — передаётся только адрес. Поэтому в вызове достаточно имени массива:

```cpp
Tiseg<4> timer(digitPins, segmentPins, BUTTON); // массив «превращается» в указатель
```

> ⚠️ Частая ошибка: написать `const uint8_t digitPins` **без звёздочки** — тогда параметр станет одиночным байтом, и код не скомпилируется.

### 4. Список инициализации конструктора
```cpp
Tiseg(...) : _disp(digitPins, segmentPins), _btn(buttonPin) {}
```
После двоеточия — **member initializer list**: члены класса создаются сразу с нужными аргументами, до входа в тело `{}`. Для объекта `_disp` это единственный способ передать пины, т.к. у него нет конструктора по умолчанию.

### 5. Композиция: объект внутри объекта
```cpp
private:
  DispBare<DIGITS, true, true> _disp;   // «у Tiseg ЕСТЬ дисплей»
  uint8_t _btn;                          // «у Tiseg ЕСТЬ пин кнопки»
```
`Tiseg` не наследует GyverSegment, а **содержит** его объект и делегирует ему работу (`_disp.tick()`, `_disp.clearPrintR(...)`). Параметры `DispBare<DIGITS, true, true>`: разряды, общий анод (`true`), динамическая индикация (`true`).

### 6. Ссылка-параметр: `bool& blinked`
```cpp
bool handlePauseAndExit(int currentNum, bool& blinked);
```
`bool&` — **ссылка**: метод получает не копию флага, а саму переменную из `runTimer()`. Изменения внутри метода видны снаружи. (В текущей логике флаг только читается, но сигнатура оставляет возможность управлять им.)

### 7. `unsigned long` и паттерн `millis()`
```cpp
unsigned long startTime = millis();
while (millis() - startTime < 1000) { ... }
```
- `millis()` — миллисекунды с включения платы, растёт всегда;
- `unsigned long` (0 … 4 294 967 295) нужен, т.к. `int` переполнится за ~32 с;
- разность `millis() - startTime` — «неблокирующая задержка»: внутри `while` код продолжает работать (крутит `tick()`, читает кнопку), в отличие от `delay()`, который замораживает всё.

### 8. `while` как ожидание события
```cpp
while (digitalRead(_btn) == LOW)  _disp.tick();  // ждём ОТПУСКАНИЯ
while (digitalRead(_btn) == HIGH) _disp.tick();  // ждём НАЖАТИЯ
```
Каждый такой цикл — состояние «ждать, пока условие истинно». `disp.tick()` внутри обязателен: иначе на время ожидания дисплей погаснет.

### 9. `return` для аварийного выхода
```cpp
if (handlePauseAndExit(num, blinked)) {
    return;   // мгновенно выйти из runTimer(), прервав for и while
}
```
`return` внутри вложенных циклов — единственный способ мгновенно прервать отсчёт и вернуть управление в `loop()`.

### 10. Соглашение об именах
Поля класса начинаются с `_` (`_disp`, `_btn`) — чтобы не путать их с параметрами методов и локальными переменными.

## Как работает логика внутри

### Временная диаграмма одной секунды

```
t, мс:    0 ─────── 500 ─────── 1000
Дисплей:  [ цифра N горит ][ погашен ][ цифра N+1 ...
                            ↑
                    «мигание» перед сменой
```

- `0–500 мс` — цифра горит;
- `500 мс` — `clear()` + `update()`, флаг `blinked = true`;
- `1000 мс` — конец `while`, `for` переходит к `num+1` и сразу зажигает новую цифру.

### Конечный автомат

```
[ПРОСТОЙ: 0000] --нажатие--> [СЧЁТ 0..N]
      ▲                          |  нажатие (2-я половина секунды)
      |                          v
      |                      [ПАУЗА: цифра заморожена]
      |                          |  второе нажатие
      |                          v
      +-------------------- [СБРОС: 0000]
                                 
[СЧЁТ] --дошли до N--> [ФИНИШ: горит N] --нажатие--> [СБРОС: 0000]
```

| Состояние | Где реализовано |
|-----------|-----------------|
| ПРОСТОЙ | `loop()` скетча: `tick()` + `isButtonPressed()` |
| СЧЁТ | `runTimer()`, цикл `for` + `while(millis…)` |
| ПАУЗА / СБРОС | `handlePauseAndExit()` |
| ФИНИШ / ожидание | `waitForReset()` |

### Кнопка: рёбра, а не уровень
Библиотека реагирует не на «кнопка нажата», а на **переходы**: нажатие → отпускание → нажатие → отпускание. Поэтому каждое действие срабатывает ровно один раз, даже если палец держат долго.

## Примеры

### Секундомер на 60 секунд
```cpp
#include <Tiseg.h>
const uint8_t d[] = {9, 10, 11, 12};
const uint8_t s[] = {1, 2, 3, 4, 5, 6, 7, 8};
Tiseg<4> t(d, s, 13);
void setup() { t.begin(); }
void loop() {
  t.tick();
  if (t.isButtonPressed()) t.runTimer(60);
}
```

### Два дисплея разной разрядности
```cpp
Tiseg<4> big(d4, s4, 9);   // 4 разряда
Tiseg<2> small(d2, s2, 8); // 2 разряда
void loop() {
  big.tick(); small.tick();
  if (big.isButtonPressed())   big.runTimer(9999);
  if (small.isButtonPressed()) small.runTimer(99);
}
```

## Типичные ошибки

| Симптом | Причина | Решение |
|---------|---------|---------|
| Дисплей гаснет в простое | нет `tick()` в `loop()` | вызывать `timer.tick()` каждый проход |
| Мерцание во время пауз | где-то используется `delay()` вместо `disp.delay()` | внутри классовых ожиданий крутить `_disp.tick()` |
| Кнопка срабатывает дважды | дребезг | увеличить антидребезг в `isButtonPressed()` до 100 мс |
| Кракозябры вместо цифр | перепутан порядок сегментов | сверить `segmentPins[]` с распиновкой A–G, DP |
| Ошибка компиляции про `digitPins` | в конструкторе потеряна `*` | тип должен быть `const uint8_t* digitPins` |
| Таймер «не видит» кнопку | в `loop()` посторонние `delay()` | убрать блокирующие задержки из `loop()` |
